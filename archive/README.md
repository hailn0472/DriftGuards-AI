# Archived Content

This folder contains archived code and documentation that is no longer actively maintained but kept for historical reference.

## 📦 Contents

### data-example/
**Original example data and deployment scripts from early development.**

This folder contains the original example Pulumi deployment that was used during early development and testing phases. It includes:

- Pulumi configuration files
- Deployment scripts (PowerShell and Bash)
- Setup and cleanup utilities
- Example documentation
- Status and guide files

**Status:** Archived - No longer actively maintained

**Reason for archiving:** 
- Replaced by more organized examples in `examples/pulumi-ec2-deployment/`
- Functionality has been integrated into main application
- Kept for historical reference and migration purposes

**Last Active:** November 2025
